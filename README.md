# TERRPG — Godot foundation

This folder is the beginning of the Godot 4 remake.

## Current milestone

### Player
- CharacterBody2D controller
- A/D or arrow-key movement
- Acceleration and friction
- Gravity
- Jumping
- Camera follow with smoothing

### Procedural world
- Seeded generation
- Rolling surface terrain
- Grass, dirt, stone and ore blocks
- Underground cave pockets
- Procedural trees
- Surface collision for the player

## Run

Open `godot/project.godot` with Godot 4.x and press **Play Project**.

The visuals are intentionally original placeholder art for now. The next milestones can replace the debug rendering with a proper tileset and then add block interaction, inventory, crafting and enemies.
