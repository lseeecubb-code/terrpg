# TERRPG

An original browser sandbox combining Terraria-style 2D mining/building gameplay with the RPG systems and story structure from my other game.

## One-file launch

Open **`index.html`** directly in a modern browser. It contains the visual HTML/CSS shell and the full JavaScript game engine in one file, with no external runtime dependencies.

## Gameplay

- Smooth A/D + arrow-key movement
- Jumping, gravity and collision
- Mouse mining, building and enemy attacks
- Procedural terrain, caves, trees and ores
- 10-slot hotbar and inventory
- Day/night cycle
- Enemy encounters, XP, levels and coins
- Equipment, spells, perks and companions
- Campaign chapters 0–10
- Named story regions, NPCs and bosses from the RPG project
- Crafting recipes and progression
- Bestiary, quest log and achievements
- World map
- Save/load codes using browser storage
- Mobile touch movement

## Menu system

The menu is an original sandbox UI with familiar categories:

**Resume, Inventory, Crafting, Character, World Map, Bestiary, Quests, Achievements, Settings, Save/Load, Controls, Main Menu.**

It is designed to provide a similar *category and flow* to a console-style sandbox menu without copying Terraria's exact interface, artwork, text, or proprietary assets.

## Controls

- **A / D** or **Arrow Keys** — move
- **Space / W** — jump
- **Left Click** — mine or attack
- **Right Click** — place selected block
- **1–0** — choose hotbar slot
- **E** — inventory
- **C** — crafting
- **M** — world map
- **Esc** — open menu

## Relationship to the RPG project

The sandbox incorporates original content themes and systems from **rpg-game**, including its chapter progression, story regions, named characters, companion concepts, gear families, spells/perks, enemy/boss names, crafting progression, bestiary and save-oriented progression.

The implementation here is a new browser game engine rather than a copy of the original terminal UI.
