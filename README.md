# TERRPG

A small original Terraria-style sandbox game made with HTML5 Canvas and JavaScript.

## Features

- Play / controls / pause menus
- A/D and arrow-key movement
- Jumping and collision physics
- Procedural terrain, caves, trees, and ores
- Mining and block placement
- Hotbar and inventory counts
- Slime enemies and combat
- Health and respawning
- Mobile touch controls

## Run

Open `index.html` in a modern web browser.

This project is an original implementation and does not include Terraria code or assets.
